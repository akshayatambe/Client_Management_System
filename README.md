# Pulse CRM – Client Management System

Pulse CRM is a modern and responsive Client Management System developed to help businesses efficiently manage leads, deals, activities, and customer interactions in one centralized platform. The application provides a clean dashboard, sales pipeline tracking, activity monitoring, and authentication system with a user-friendly interface.

This project is designed using modern frontend technologies and follows a professional CRM workflow similar to real-world SaaS applications.

# Features
1) User Authentication (Login & Signup)
The application includes a secure authentication system that allows users to create accounts and log in safely. Supabase Authentication is used to manage user sessions and protect dashboard routes from unauthorized access. The authentication flow ensures secure login handling and persistent user sessions.

2) Modern Landing Page
Pulse CRM provides a professional and modern landing page with a responsive layout, attractive UI design, feature highlights, and call-to-action buttons. The landing page is designed to give users a clean introduction to the CRM platform similar to real SaaS applications.

3) Dashboard Analytics
The dashboard provides a centralized overview of important CRM activities, including leads, deals, tasks, and analytics. Users can quickly monitor sales activity, track performance, and view real-time statistics through charts and summary cards.

4) Lead Management System
The system allows users to efficiently manage customer leads by adding, updating, deleting, and tracking lead information. This feature helps organize potential clients and improve customer relationship management.

5) Deal Pipeline Tracking
The application includes a deal pipeline system that helps users visualize different stages of sales processes such as prospect, negotiation, won, and lost deals. This improves sales tracking and workflow organization.

6) Activity Monitoring
Users can manage and monitor daily activities such as calls, meetings, follow-ups, and tasks. This feature helps maintain productivity and ensures proper tracking of customer interactions.

7) Responsive UI Design
The user interface is fully responsive and optimized for desktop, tablet, and mobile devices. Tailwind CSS is used to create a clean, modern, and flexible design system for better user experience.

8) Secure Authentication using Supabase
Supabase provides backend authentication and secure database connectivity. User data and sessions are securely managed using Supabase services, ensuring safe access control and reliable backend integration.

9) Real-Time Data Handling
The application supports dynamic and real-time data updates, allowing users to instantly view changes in leads, deals, and activities without requiring manual page refreshes.

10) Clean and Professional Interface
Pulse CRM follows modern UI/UX principles with organized layouts, proper spacing, smooth navigation, and professional dashboard components to create an intuitive user experience.

# Technologies Used

## Frontend Technologies

### React.js
React.js is used for building the user interface using reusable components and efficient rendering techniques. It helps create a fast, dynamic, and interactive single-page application.

### TypeScript
TypeScript is used to add static typing and improve code quality, maintainability, and scalability. It helps reduce runtime errors and improves developer productivity.

### Tailwind CSS
Tailwind CSS is used for designing the user interface with utility-first CSS classes. It enables rapid UI development and helps create responsive and modern layouts efficiently.

### TanStack Router
TanStack Router is used for handling client-side routing and navigation within the application. It provides structured route management and protected routing functionality.

### Vite
Vite is used as the frontend build tool and development server. It provides fast project startup, optimized builds, and an improved development experience.

---

## Backend / Database

### Supabase
Supabase is used as the backend service for authentication, database management, and real-time data handling. It simplifies backend development and provides secure API integration.

## Tools & Platforms

### Git & GitHub
Git is used for version control, while GitHub is used for project hosting, collaboration, and repository management.

### VS Code
Visual Studio Code is used as the primary code editor for developing and managing the project efficiently with extensions and debugging support.
